# PROJECT 1990: FOOTBALL LEGEND

1990년에 태어난 축구선수 한 명의 인생을 **0세부터 36세까지** 시뮬레이션하는 텍스트 기반
라이프 시뮬레이션 RPG의 작동하는 프로토타입.

경기를 직접 플레이하지 않는다. 대신 부모를 설득하고, 클럽을 고르고, 부상을 견디고, 은퇴를 결정한다.

```bash
node build.mjs && open dist/index.html   # 플레이
node tools/batch.mjs                     # 엔진 검증 (지역×가정 6조합 × 1000회)
```

의존성 0. 빌드 도구 없음. `node` 하나만 있으면 된다.

---

## 1. 이 프로토타입이 증명하려는 것

기획의 핵심 명제는 **"재능이 인생을 결정하지 않는다"** 였다. 그래서 가장 먼저 만든 것은
UI가 아니라 **검증기**다.

> 같은 엔진에 서로 다른 출생 조건을 넣었을 때, 결과 분포가 실제로 갈라지는가?

`node tools/batch.mjs` 실행 결과 (각 800회, 부모 = 근로자 가문):

| 결과 | 🇪🇸 바르셀로나 | 🇺🇸 LA 사우스 센트럴 |
|---|---:|---:|
| 1부 리그 이상 프로 | **10.9%** | **1.0%** |
| 축구로 급여를 받은 인생 | 25.0% | 10.0% |
| 축구를 그만둔 인생 | 7.1% | 33.6% |
| 끝까지 프로가 되지 못함 | 41.1% | 38.4% |

**미국 트랙의 "헬난이도"는 하드코딩된 난이도 배수가 아니다.** Pay-to-Play 비용 장벽,
낮은 스카우트 밀도(27 vs 85), 강력한 대체 스포츠(농구 친화도 88)라는 세 개의 환경 변수가
상호작용해서 만들어진 **창발적 결과**다. 엔진 코드 어디에도 `if (USA) difficulty *= 2`는 없다.

동일한 잠재력을 가진 두 선수가 다른 인생을 사는지도 확인된다:

```
PA 96 → 전성기 74 (쓰지 못한 재능 22)  Alejandro Cabrera
  동네 클럽 → 2002 바르셀로나 유소년 탈락 → CD Tenerife
  → Wake Forest (NCAA) → Real Betis → AFC Ajax
  전환점: 2002년 유소년 탈락 / 가장 후회되는 순간: 2012년, 그 팀 앞에서 아무것도 못 했다
```

## 2. 아키텍처

가장 중요한 설계 결정은 **판정과 서술의 분리**다.

```
[결정론적 시뮬레이션] → [상태/확률] → [사건] → [선택] → [결과] → [자연어 서술]
        ↑                                                           ↑
   엔진이 담당                                              나중에 LLM이 담당 가능
```

```
src/engine.js     시뮬레이션 엔진 — DOM 의존 0, 순수 함수. 모든 판정이 여기서 일어난다.
web/app.js        UI 레이어 — 엔진 상태를 "표시"만 한다. 어떤 판정도 하지 않는다.
web/style.css     시각 디자인
tools/batch.mjs   헤드리스 검증기 (Node)
build.mjs         단일 파일 인라인 빌드 → dist/
```

엔진과 UI가 분리되어 있으므로:
- **브라우저 UI와 Node 배치 러너가 같은 엔진을 공유한다** (검증한 것이 곧 플레이되는 것)
- 나중에 React/Vue/React Native 셸을 얹을 때 시뮬레이션 코드를 건드리지 않는다
- LLM으로 서술을 생성하게 바꿔도 게임 자체는 유지된다

## 3. 구현된 시스템

### 가변형 타임라인 (Hybrid Turn System)
```
0~15세   → 1년 단위    (속도감 있는 성장 및 부모 설득)
16~29세  → 반년 단위   (여름/겨울 이적시장, 시즌 중 부상·감독 교체)
30~36세  → 1년 단위    (에이징 커브, 로테이션, 커리어 마무리)
```
1회차 약 **40~48턴**. 유년기의 빈 해는 클릭을 요구하지 않고 조용히 넘어간다
(그 클릭이 곧 피로도이기 때문).

### 4층 데이터 구조

| 층 | 내용 | 공개 |
|---|---|---|
| Visible | 주력·드리블·패스·슈팅·피지컬·전술이해·판단력 (1~20) | 항상 |
| Socio-economic | 연봉·누적자산·광고수입·SNS 팔로워·가문 내 영향력 | 항상 |
| Semi-hidden | 감독 신뢰, 부모의 축구 수용도, 평판 | 항상 |
| **Hidden** | **잠재력(PA)·유리몸 지수·빅매치 멘탈·적응력·독기·훈련 흡수율** | **은퇴 후에만** |

플레이 중 잠재력은 `????`로만 표시된다. 커리어가 끝난 뒤에야 PA가 공개되고,
**"쓰지 못한 재능"이 몇 점이었는지** 알게 된다.

### 환경 천장 (Environmental Ceiling) — 엔진의 핵심
```js
devEnv  = 11~22세에 겪은 훈련 환경의 지수이동평균
ceiling = PA × (0.52 + 0.48 × normalize(devEnv))
```
잠재력은 "도달 가능한 수치"가 아니라 **환경이 허락하는 만큼만 열리는 수치**다.
PA 94를 갖고 태어나도 AYSO 리크리에이션 리그에서만 자랐다면 60대에서 끝난다.
이 한 줄이 기획의 명제를 수치로 옮긴 부분이다.

### 사건마다 다른 확률분포
| 사건 | 분포 | 이유 |
|---|---|---|
| 부상 심각도 | Heavy-tail (α=1.55) | 대부분 경미, 드물게 커리어를 끝낸다 |
| 성장 폭발 | Right-skewed | 극소수만 크게 터진다 |
| 잠재력 상한 | Right-skewed | 대부분 60~75, 90+는 희귀 |
| 경기력 | 정규분포 | 평균 주변에서 흔들린다 |

부상은 "운"이 아니라 **조건부 확률**이다:
```
P(부상) = 기본률 × (0.5 + 출전부하) × 유리몸지수/55 × 나이계수 × 스트레스계수 × 과훈련플래그
```
그래서 플레이어는 "운이 나빴다"가 아니라 **"내가 혹사시켰구나"** 라고 느낀다.

### 스카우트 평가 오차
```
최종 평가 = 실제 능력 × 0.75 + 스카우트 오차 × 0.15 + 당일 컨디션 × 0.10
```
같은 선수를 클럽마다 다르게 본다. 노출도가 높은 클럽일수록 오차가 작다.
12세 유소년 테스트는 **또래 평균 대비**로 채점된다 (성인 스케일로 재면 아무도 통과하지 못한다).

### 기억 시스템 (Memory) — 스토리 생성보다 스토리 *회수*
사건은 `{year, age, tag, text, importance, people}` 로 기록되고, 나중에 다시 소환된다.

- 12세에 유소년 테스트에서 탈락 → **10년 뒤 그 팀을 상대로 만나는 이벤트**가 발생
- 8세에 "성적 유지할게요"라고 부모를 설득 → **31세에 아버지가 그 약속을 다시 꺼낸다**
- 어머니가 야간 근무를 늘려 클럽 회비를 냄 → 엔딩에서 "가장 중요했던 사람"으로 기록

### 가문 엔진 (Parents Convincing Engine)
- 부모 3계층: 상위 엘리트(학업 압박 86) / 체육인 가문(축구 이해도 88) / 근로자(위기 취약도 88)
- **형제 대박 이벤트**: 유소년기 중 낮은 확률로 형이 집안을 살리면 진로 압박이 급감 (패시브)
- **사촌 라이벌**: 주인공의 성공에 자극받아 독기를 품고 성장. 4단계로 관계가 격화된다
- 아버지/어머니가 서로 다른 가중치로 판단한다 (아버지는 경제성, 어머니는 안전/교육)

### 시대 고증 이벤트
역사는 컷신이 아니라 **세계의 확률분포를 바꾼다**.

| 연도 | 사건 | 엔진에 미치는 효과 |
|---|---|---|
| 1994 | 미국 월드컵 | 축구 의지 상승, 지역 축구 열기 |
| 2001 | FIFA 18세 미만 국제이적 제한 | 18세 미만 해외 이적 차단 |
| 2002 | 한일 월드컵 (미국 8강) | 🇺🇸 스카우트 밀도 +9, 부모 수용도 +10 / 🇪🇸 유소년 경쟁률 상승 |
| 2008 | 세계 금융위기 | 가계 타격 → 학업을 밀던 부모가 **당장 현금이 되는 프로 계약**을 권하는 아이러니 |

그 밖에: MLS Generation adidas 계약, 스페인 후베닐 B 아마추어 신분 유지 → NCAA 우회 트랙,
FIFA 규정에 따른 국가대표 변경(메이저 대회 출전 시 영구 봉인), 바이럴 PR 마케팅.

### 엔딩
10개 엔딩 루트 (검증 결과 1500회 중 10개 전부 도달 확인). 실패가 게임오버가 아니다.

`All-Time Great` `Top-Flight Regular` `The Professional` `Second Division Lifer`
`Semi-Pro` `The College Route` `The Unfulfilled Genius` `The Coach`
`The One Who Walked Away` `One of the Many`

은퇴 시 **커리어 전기(Career Biography)** 가 자동 생성된다: 통산 기록, 커리어 경로,
전환점, 가장 후회되는 순간, 가장 중요했던 사람, 라이벌의 최종 성적, 인생 타임라인,
그리고 마지막에 공개되는 PA와 "쓰지 못한 재능".

## 4. 밸런싱은 검증기가 잡았다

이 프로젝트에서 검증기를 UI보다 먼저 만든 이유. 첫 실행에서 바로 드러난 버그들:

| 증상 | 원인 |
|---|---|
| PA 85가 최고 73에서 멈춤 | 성장 계수가 너무 낮아 아무도 잠재력에 근접하지 못함 |
| 전원이 PA를 정확히 달성 | 반대로 과보정 — 환경이 결과에 영향을 주지 않게 됨 → **환경 천장** 도입 |
| 통산 950경기 | 유소년 경기가 통산 기록에 합산됨 |
| 스페인 18세가 Columbus Crew 입단 | 금융위기 이벤트가 국적 필터 없이 클럽을 추첨 |
| 지도자 전환 16.6% | 아마추어에 머문 인생을 "지도자"가 덮어씀 |
| All-Time Great 0% | 은퇴 시점 평판으로 판정 — 36세의 평판은 이미 내려앉아 있음 |
| **All-Time Great 12%** | **라 마시아 U15 출전이 "세계 최상위 도달"로 집계됨** |
| 14세가 시즌 1경기 | 유소년 선발을 성인 요구치로 판정 |

마지막 두 개가 가장 교훈적이다. 유소년 선발 기준을 또래 대비로 고치자
*즉시* All-Time Great이 12%로 폭증했다 — 유소년 출전 기록과 유소년 평판이
성인 커리어로 새고 있었기 때문. 두 경로를 senior-only로 막아서 해결했다.

## 5. 이 프로토타입이 하지 않는 것

의도적으로 범위를 좁혔다. MVP는 **엔진의 깊이**에 자원을 몰아주는 것이 목표였다.

- **경기 플레이 없음.** 90분 실시간 개입은 없고, 기간 단위 자동 시뮬레이션 + 서술이다.
- **LLM 서술 없음.** 서술 텍스트는 현재 하드코딩되어 있다. 다만 엔진/서술이 분리되어
  있으므로 `pushLog` 지점을 LLM 호출로 교체하면 그대로 동작한다.
- **지역 2개 / 부모 3계층.** 기획서의 국적 4개(이탈리아·한국) 중 2개만 구현.
- **엔딩 2025개 아님.** 10개 메인 루트 + 기억 조합에 따른 전기 변형까지다.
- **React/Vue 아님.** 엔진을 브라우저와 Node가 공유해야 하고 단일 파일로 배포해야 해서
  바닐라 JS로 갔다. 엔진에 DOM 의존이 없으므로 프레임워크 셸은 나중에 얹을 수 있다.
- **세이브 없음.** seed를 입력하면 같은 인생이 재현된다 (결정론적 RNG).

## 6. 다음에 붙일 순서

1. **LLM 서술 레이어** — 상태를 프롬프트로 넘겨 사건 묘사/대사를 생성. 판정은 계속 엔진이.
2. **선택지 동적 생성** — 성격 벡터에 맞는 선택지를 LLM이 만들고, 결과는 엔진이 계산.
3. 이탈리아 / 한국(군 문제) 트랙
4. 세계 시뮬레이션 심화 — 클럽 재정·감독 교체·승강이 독립적으로 움직이게
5. 세이브/불러오기, 명예의 전당(여러 회차 누적)
