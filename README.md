# PROJECT 1990: FOOTBALL LEGEND

1990년생 축구선수 한 명의 인생을 **16세부터 36세까지** 시뮬레이션하는 텍스트 기반 라이프
시뮬레이션 RPG의 작동하는 프로토타입. 시작할 때 이름·포지션·국적을 고른다.

경기를 직접 플레이하지 않는다. 대신 매 시즌 이적시장에서 클럽을 고르고, 부상을 견디고,
국가대표 소집을 기다리고, 은퇴를 결정한다. 0~15세(바르셀로나 유소년 시절)는 헤드리스로
시뮬레이션되어 **배경설정 산문**으로만 제시된다 (클릭을 요구하지 않는다).

```bash
node build.mjs && open dist/index.html   # 플레이
node tools/batch.mjs                     # 엔진 검증 (여러 회차 시뮬 → 결과 분포)
```

의존성 0. 빌드 도구 없음. `node` 하나만 있으면 된다.

---

## 1. 이 프로토타입이 증명하려는 것

기획의 핵심 명제는 **"재능이 인생을 결정하지 않는다"** 였다. 그래서 가장 먼저 만든 것은
UI가 아니라 **검증기**다.

> 같은 곳(능력 50)에서 출발한 두 선수가, 왜 전혀 다른 인생을 사는가?

시작할 때 **이름·포지션·국적**만 고른다. 모든 선수는 **능력 50으로 동일하게 출발**한다.
갈라지는 것은 잠재력(성장 *속도*), 겪는 부상, 잡거나 놓치는 기회, 그리고 선택과 운이다.
가정환경·가계·부모 같은 사회경제 레이어는 두지 않는다 — 순수한 축구 커리어 시뮬레이션이다.

`node tools/batch.mjs` 실행 결과 (600회):

| 지표 | 값 |
|---|---:|
| 프로 진출 | ~70% |
| 1부 정착 (T1~T3) | ~42% |
| 발롱도르 (T1) | ~8% |
| Bad End | ~1% |

능력이 같아도 결과가 크게 벌어진다. 그 차이는 능력치 보너스가 아니라 **성장 속도(잠재력)와
기회·선택·운**에서 나온다.

---

## 2. 아키텍처

가장 중요한 설계 결정은 **판정과 서술의 분리**다.

```
[결정론적 시뮬레이션] → [상태/확률] → [사건] → [선택] → [결과] → [자연어 서술]
        ↑                                                           ↑
   엔진이 담당                                              나중에 LLM이 담당 가능
```

```
src/engine.js     시뮬레이션 엔진 — DOM 의존 0, 순수 함수. 모든 판정이 여기서 일어난다.
web/app.js        UI 레이어 — 엔진 상태를 "표시"만 한다. 어떤 판정도 하지 않는다.
web/style.css     시각 디자인 (Copero Edition)
tools/batch.mjs   헤드리스 검증기 (Node)
build.mjs         단일 파일 인라인 빌드 → docs/ (GitHub Pages), dist/
```

엔진과 UI가 분리되어 있으므로:
- **브라우저 UI와 Node 배치 러너가 같은 엔진을 공유한다** (검증한 것이 곧 플레이되는 것)
- 나중에 React/Vue 셸을 얹을 때 시뮬레이션 코드를 건드리지 않는다
- LLM으로 서술을 생성하게 바꿔도 게임 자체는 유지된다

## 3. 구현된 시스템

### 가변형 타임라인 (Hybrid Turn System)
```
0~15세   → 헤드리스   (배경설정 산문으로만 제시, 클릭 없음)
16~29세  → 반년 단위   (여름/겨울 이적시장, 시즌 중 부상·감독 교체)
30~36세  → 1년 단위   (에이징 커브, 로테이션, 커리어 마무리)
```
플레이 구간은 16세부터. 1회차 약 **35턴**.

### 능력 구조 — 단일 수치 + 히든 잠재력

세부 스탯(드리블·패스·슈팅…)을 두지 않는다. **평균 능력(Current Ability)** 단일 수치다.

| 층 | 내용 | 공개 |
|---|---|---|
| Visible | 평균 능력(OVR)·포지션·소속·리그·주급·평판 | 항상 |
| Semi-hidden | 감독 신뢰, 자신감, 폼 | 항상 |
| **Hidden** | **잠재력(PA)·유리몸 지수·빅매치 멘탈** | **은퇴 후에만** |

플레이 중 잠재력은 공개되지 않는다. 커리어가 끝난 뒤에야 PA가 공개되고,
**"쓰지 못한 재능"이 몇 점이었는지** 알게 된다.

### 시작 능력 고정 + 잠재력 = 성장 속도

```js
START_OVR = 50            // 전원 동일
potential = rng.int(58, 99)   // 균등분포, 히든
growthSpeed(p) = clamp(0.75 + (PA − 58) × 0.01622, 0.6, 1.45)
```

모두가 50에서 출발한다. 잠재력은 "도달할 수치"가 아니라 능력이 **얼마나 빨리 오르는가**를
정한다. 잠재력은 균등분포라 특정 구간에 몰리지 않는다. 피크는 28세, 이후 완만한 하강.

### 성장 천장 (Development Ceiling)
```js
devEnv  = 11~22세에 겪은 훈련 환경(소속 유소년팀·아카데미 수준)의 지수이동평균
ceiling = PA × (0.72 + 0.28 × normalize(devEnv))   // 하한 START_OVR + 3
```
잠재력이 높아도 좋은 훈련 환경(라 마시아 합격 등)에 닿지 못하면 그 수치에 도달하지 못한다.
어느 유소년팀에서 자랐는가 — 그 기회가 천장을 정한다.

### 세미프로 락 (18세 프로 진입에 실패하면)

18세에 13개 요인으로 계산한 프로 진입 점수가 문턱을 넘지 못하면 **세미프로(3부)에 6년간
고정**된다. 그 기간 능력 상승 속도는 ×0.5. 24세 이후에야 1·2부 진출이 허용된다.
취업·대학진학·가업 계승 같은 이탈 선택지는 없다 — 축구를 계속한다.

### 사건마다 다른 확률분포
| 사건 | 분포 | 이유 |
|---|---|---|
| 부상 심각도 | Heavy-tail | 대부분 경미, 드물게 커리어를 끝낸다 |
| 성장 노이즈 | Right-skewed | 극소수만 크게 터진다 |
| 잠재력 | 균등분포 (58~99) | 특정 구간에 몰리지 않는다 |
| 경기력 | 정규분포 | 평균 주변에서 흔들린다 |

부상은 유형화돼 있다 (타박/근육/발목/골절/햄스트링/아킬레스/십자인대). 중상은 즉시
OVR −5~−10 + 잠재력 손실 + 유리몸 지수 상승을 남긴다.

### 스카우트 평가 오차
```
최종 평가 = 실제 능력 × 0.75 + 스카우트 오차 × 0.15 + 당일 컨디션 × 0.10
```
같은 선수를 클럽마다 다르게 본다. 노출도가 높은 클럽일수록 오차가 작다.
유소년 테스트는 **또래 평균 대비**로 채점된다.

### 기억 시스템 (Memory) — 스토리 생성보다 스토리 *회수*
사건은 `{year, age, tag, text, importance, people}` 로 기록되고, 나중에 다시 소환된다.
유소년 탈락 → 10년 뒤 그 팀을 상대로 만나는 이벤트, 커리어 전환점 → 엔딩 전기의
"전환점/가장 후회되는 순간" 같은 식으로 인과가 이어진다.

### 시대 고증 이벤트 (61개)
역사는 컷신이 아니라 **세계의 확률분포를 바꾼다**. 각 이벤트는 발생 시 `[이번 기간에
미치는 영향]` 을 실제 엔진 효과에서 생성해 표시한다 (설명과 판정이 어긋나지 않는다).

| 연도 | 사건 | 엔진에 미치는 효과 (예) |
|---|---|---|
| 2001 | FIFA 18세 미만 국제이적 제한 | 18세 미만 해외 이적 차단 |
| 2008 | 세계 금융위기 | 이적시장 동결 — 빅클럽 외 오퍼·재계약 인상 감소 |
| 2020 | 팬데믹 | 시즌 경기 수 감소 (×0.72) |
| 2023~ | 사우디 리그 자본 유입 | 특정 조건에서 주급 대폭 상승 |

### 국가대표

소집은 **포지션 경쟁 우선**으로 판정한다: 같은 포지션의 대표팀 평균과 먼저 비교하고,
그 다음 대표팀 전체 평균·폼·평판·국제 경험을 가중한다. 포지션 희소성(GK·CB 우대)과
폼 폭발은 가점, 부상은 감점. 소집 후 역할은 대표팀 평균 대비 격차로 CORE/LEADER/
SQUAD/FRINGE 4단계로 갈리고, 서술이 각각 달라진다. 3부 소속은 A매치에 소집되지 않는다.

### 엔딩 (9 티어)

**9개 티어 엔딩.** 실패가 게임오버가 아니다.

```
T1 All-Time GOAT   T2 Global Megastar   T3 대륙급 에이스
T4 1부 리그 스타터  T5 하부리그 저니맨    T6 로컬 벤치 워머
Bad End 뒷골목      Normal End 생활인     Success End 타 분야 성공
```

은퇴 시 **커리어 전기**가 자동 생성된다: 연도별 통산 기록, 커리어 경로, 전환점,
가장 후회되는 순간, 인생 타임라인, 그리고 마지막에 공개되는 PA와 "쓰지 못한 재능".

## 4. 밸런싱은 검증기가 잡았다

이 프로젝트에서 검증기를 UI보다 먼저 만든 이유. 실행에서 드러난 대표적 버그들:

| 증상 | 원인 |
|---|---|
| PA 85가 최고 73에서 멈춤 | 성장 계수가 너무 낮아 아무도 잠재력에 근접하지 못함 |
| 전원이 PA를 정확히 달성 | 반대로 과보정 → **성장 천장** 도입 |
| 통산 950경기 | 유소년 경기가 통산 기록에 합산됨 |
| 3부 소속인데 월드컵 차출 | `ntEligible` 에 디비전 게이트 부재 + 캡 누적 저장 버그 |
| 3부에서 승격 1.5% | 정적 평판 백분위가 3σ를 요구 → 리그 parity + 선수 lift 도입 |
| 이벤트가 안 보임 | `pending.body` 를 화면에 렌더하지 않았음 (가장 영향 컸던 수정) |
| All-Time Great 0%→12% | 유소년 출전·평판이 성인 커리어로 샘 → senior-only 게이트 |

핵심 방법은 하나다: **고치기 전에 측정한다.** 증상과 원인이 다른 경우가 반복됐다.

## 5. 이 프로토타입이 하지 않는 것

의도적으로 범위를 좁혔다. MVP는 **엔진의 깊이**에 자원을 몰아주는 것이 목표였다.

- **경기 플레이 없음.** 기간 단위 자동 시뮬레이션 + 서술이다.
- **LLM 서술 없음.** 서술 텍스트는 현재 하드코딩. 엔진/서술이 분리돼 있으므로
  서술 지점을 LLM 호출로 교체하면 그대로 동작한다.
- **스페인 단일 트랙.** 기획서의 다국적 트랙(이탈리아·한국 등)은 미구현.
- **세이브 없음.** seed를 입력하면 같은 인생이 재현된다 (결정론적 RNG).

## 6. 다음에 붙일 순서

1. **LLM 서술 레이어** — 상태를 프롬프트로 넘겨 사건 묘사/대사를 생성. 판정은 계속 엔진이.
2. **선택지 동적 생성** — 성격 벡터에 맞는 선택지를 LLM이 만들고, 결과는 엔진이 계산.
3. 영입 판정 정교화 — 구단 재정·유소년 정책·포지션별 팀 내 경쟁자 반영.
4. 이탈리아 / 한국(군 문제) 트랙.
5. 세이브/불러오기, 명예의 전당(여러 회차 누적).
